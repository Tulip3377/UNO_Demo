# basic_demo
<p>
  <h1>
    UNO Game in Python
  </h1>
A simple command-line UNO game built with Python. The project implements the basic mechanics of UNO including playing cards, drawing cards, taking turns, and determining the winner.
</p>
<h1>
  Features
  </h1>

  
 <li>UNO-style card deck</li>
 <li>Turn-based gameplay</li>
 <li>opponent</li> 
 <li>Draw cards when no playable card is available</li>
 <li>Action cards</li>
 <li>Automatic win detection</li>
<h1>Technologies Used</h1>
<li>Python 3</li>

<h1>How to Run</h1>
<ol>
 <li>Clone this repository: <br>
git clone https://github.com/Tulip3377/UNO.Demo.git</li> 
<li>Open the project folder: <br>
cd uno-game</li>
<li>Run the game: <br>
python uno.py</li>
</ol>

<h1>How to Play</h1>
<p>
  The game is played through the command line.<br>

On your turn, select a playable card from your hand according to the rules implemented in the program. If you cannot play a card, draw a card and continue according to the game rules.<br>

The first player to get rid of all their cards wins.
</p>
